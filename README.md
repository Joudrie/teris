# Material Blocks

A falling-block puzzle where every piece is a material with its own physics: fire, water,
wood, sand, glass, ice, stone, brick. Put materials next to what cancels them to fill the
drain bar within the level's piece budget.

Play it: https://joudrie.github.io/teris/

```sh
npm start        # serves on http://localhost:8000
npm test         # rules, session, edge cases and every mechanic test card
```

Design notes, test cards, win rates, the bug log and how to re-run every check:
see [DESIGN.md](DESIGN.md).
